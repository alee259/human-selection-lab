Understanding Human Evolution

Explore the biological mechanisms behind each scenario and how the simulation models evolution.

Behind the Simulation: One Generation at a Time

The model begins at generation 0 with a tracked allele frequency p. The other allele has frequency q = 1 - p. Each generation applies only the forces you enabled, in the fixed order below.

  1. Mutation: Some A copies change to a and some a copies change to A, according to the two rates.
  2. Gene flow: During the selected migration window, the receiving population mixes its frequency with a fixed source population.
  3. Selection: The program assumes Hardy-Weinberg genotype proportions p², 2pq and q², weights them by relative fitness, and calculates the updated tracked frequency.
  4. Drift: If enabled, the program independently samples 2N allele copies. Each copy has probability p of being the tracked allele, so the number of tracked copies follows a binomial distribution. The new frequency is the count divided by 2N.
  5. Record and repeat: Save the frequency for the new generation and repeat until the requested generation count is reached.

Why the order matters: Each step uses the previous step's output. Reordering these operations can change the result. This is a simplified model life cycle, not a universal biological sequence.

Run 10 Times: Each run starts from the same parameters but performs independent random drift sampling, so the trajectories may differ. With drift off, identical settings produce identical paths.

    How the Evolutionary Forces Work

    This simulator tracks the frequency of allele A (p) across generations. The frequency of allele a is q = 1 - p.

    Each enabled evolutionary force modifies the allele frequency before the next generation is recorded.

    1. Mutation

    Mutation changes one allele into another. Our model allows mutation in both directions.

    p' = p(1 - v) + (1 - p)u

    p = current frequency of allele A
    u = mutation rate from a to A
    v = mutation rate from A to a

    Mutation can introduce an allele that was previously absent from the population.

    2. Gene Flow

    Gene flow changes allele frequencies when migrants contribute genetic material to a receiving population.

    p' = (1 - m)p + mpₛ

    m = fraction of the receiving gene pool contributed by migrants
    pₛ = allele A frequency in the source population

    Gene flow moves the receiving population's allele frequency toward the source population's frequency. In our model, migration acts for a user-defined number of initial generations.

    3. Natural Selection

    Natural selection changes allele frequencies when genotypes have different relative fitness values.

    Before selection, the model assumes Hardy-Weinberg genotype proportions:

    AA = p²
    Aa = 2pq
    aa = q²

    Average population fitness is:

    w̄ = p²wAA + 2pqwAa + q²waa

    The frequency of allele A after selection is:

    p' = (p²wAA + pqwAa) / w̄

    wAA, wAa, and waa represent the relative fitness values of the three genotypes.

    When heterozygotes have the highest fitness, balancing selection can maintain both alleles at an intermediate frequency.

    4. Genetic Drift

    Genetic drift is random change in allele frequency caused by sampling between generations.

    X ~ Binomial(2N, p)
    p' = X / (2N)

    N = number of diploid individuals
    2N = total allele copies
    X = number of sampled A alleles

    Genetic drift is stronger in smaller populations. An allele can become lost (p = 0) or fixed (p = 1) purely through chance.

    Combining Evolutionary Forces

    When multiple forces are enabled, our simulator applies them sequentially:

    Mutation → Gene Flow → Selection → Drift

    The output of each enabled force becomes the input to the next. Because these operations are not generally interchangeable, changing their order can change the results.

    Model Assumptions & Limitations

    Wright-Fisher Population Model

    Human Selection Lab uses a simplified diploid Wright-Fisher model to simulate changes in the frequency of one tracked genetic unit.

    The population contains N diploid individuals, representing 2N copies of the tracked locus. Generations are discrete and non-overlapping, and population size remains constant during each simulation.

    Hardy-Weinberg Assumptions

    Before applying natural selection, the model calculates genotype frequencies using p², 2pq, and q².

    This assumes random mating and Hardy-Weinberg proportions at the modeled locus before selection. Real populations may depart from these assumptions.

    Constant Evolutionary Parameters

    Population size, mutation rates, and genotype fitness values remain constant throughout a run.

    Migration occurs for the specified number of initial generations, using a constant source allele frequency and migration rate.

    Order of Evolutionary Forces

    Enabled forces are applied in this order: mutation, gene flow, natural selection, and genetic drift.

    This is a modeling decision rather than a universal biological sequence. Different life-cycle assumptions can produce different results.

    Randomness and Repeated Simulations

    When genetic drift is enabled, the model randomly samples 2N allele copies each generation.

    Repeated simulations can therefore produce different trajectories even when their starting parameters are identical.

    Evolutionary Time

    Users can specify the approximate number of years represented by one generation.

    Total elapsed time is calculated by multiplying the number of generations by the selected generation length.

    This conversion does not change the evolutionary calculations.

    Real-World Population Comparisons

    The world map displays published allele or haplotype frequencies from sampled populations.

    When comparing two populations, the simulator uses their observed frequencies as starting conditions and applies the same illustrative evolutionary parameters independently.

    These trajectories do not reconstruct the actual evolutionary histories of the sampled populations.

    Scientific Limitations

    The model does not explicitly represent age structure, spatial population structure, changing population sizes, complex inheritance, or interactions among multiple genetic loci.

    Its biological scenarios simplify real evolutionary processes to demonstrate fundamental population-genetic mechanisms.

    All preset parameters are illustrative and should not be interpreted as measured historical fitness values, migration rates, or mutation rates.
